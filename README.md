# TICKBITAI — демонстрационный Telegram Mini App

React/Vite frontend + Express API для проверки пользовательских сценариев. **Это не инвестиционная платформа и не сервис платежей:** балансы, статистика, ссылки, уровни и награды — демонстрационные; приложение не торгует и не переводит деньги.

## Локальный запуск

Нужен Node.js 18+.

```sh
npm install
npm run server
```

В другом терминале:

```sh
npm run dev
```

Откройте http://localhost:3000. Vite проксирует `/api` на Express (порт 4000). Сборка фронтенда: `npm run build`. Для локального production preview: `npm run build`, затем `NODE_ENV=production npm start` и открыть порт 4000.

## Демо-сценарии

- Пять вкладок, профиль, показатели уровней и история операций.
- Тестовое пополнение (не криптоплатёж), сундуки и сохранение рефбек-настройки.
- Создание демо-заявки на вывод с минимальной суммой 0.1, проверкой тестового баланса и лимитом пяти заявок менее 10.
- Админ-метрики и список заявок доступны только при серверном `ADMIN_TOKEN`; задайте его в окружении и укажите тот же bearer-токен в демо-интерфейсе профиля.
- Шаринг реферальной ссылки, подключение Telegram WebApp close при запуске внутри Telegram.

## Проверка

После `npm install` выполните `npm run build`. Запустите API и проверьте `GET /api/health`; фронтенд использует `/api/user`, `/api/dashboard`, `/api/history`, `/api/demo/deposit`, `/api/gift/open`, `/api/referrals/settings` и `/api/withdraw`.

## Ограничения / обязательная работа до production

Данные хранятся только в оперативной памяти и сбрасываются после перезапуска; это один общий демо-пользователь. Нет проверки подписи Telegram `initData`, PostgreSQL/транзакционного журнала, реальных реферальных связей, платежного провайдера, Stars-платежей, blockchain wallet/payout, KYC/AML, антифрода, верификации Stories-задач, реального AI/торговли или полноценной админ-панели. Админ-токен защищает только demo admin API. Не подключайте реальные деньги и не публикуйте этот sandbox как финансовый продукт.
