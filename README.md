# TICKBITAI demo Mini App

React/Vite frontend with an Express API fixture for demonstrating the supplied UI flows. **This repository is not a production investment or payment service.** Balances, rates, users, referral counts, and rewards are demo data; accrual is not a real trading result, and withdrawals do not send funds.

## Run locally

Requires Node.js 18 or newer.

```sh
npm install
npm run server
```

In another terminal:

```sh
npm run dev
```

Open http://localhost:3000. The Vite dev server proxies `/api` to port 4000. For a production-style local preview, run `npm run build`, then `NODE_ENV=production npm run server` and open port 4000.

## Implemented demo flows

- Responsive five-tab interface, referral copy/share, displayed level table, stats and history.
- Demo gift box with server-side reward selection and persisted-in-process state.
- Cashback input validation and API update.
- Withdrawal request validation: amount at least 0.1, balance check, wallet field, and five micro-request cap for amounts below 10. Requests are recorded as pending demo entries; no blockchain transfer occurs.
- Admin withdrawal-list endpoint is disabled unless `ADMIN_TOKEN` is configured and sent as a bearer token. This is not a complete admin console or production identity system.

## Known limitations before production

- API state is in-memory and resets on restart; there is no PostgreSQL/Redis persistence, multi-user isolation, or transactional ledger.
- No Telegram `initData` signature verification or user authentication is implemented. Do not expose this demo API to real users or accept money.
- No deposit provider, Stars billing, wallet signing, payout provider, blockchain confirmation, KYC/AML, anti-fraud, real referral attribution, or story-task verification is configured.
- The income/rate figures in the supplied concept are only shown as demo UI values. They are not guaranteed and are not generated by AI trading.
- A production admin panel needs authenticated, role-based access and audited changes; the protected endpoint here is only a stub.
