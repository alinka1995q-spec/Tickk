# TICKBITAI — локальный demo MVP

В эту итерацию добавлены локальное сохранение состояния, демо-начисление прибыли согласно выбранному UI-уровню, перевод демо-прибыли в тестовый баланс, демо-пополнение, сундуки, рефбек, история и обработка демо-заявок из панели администратора.

## Запуск

Требуется Node.js 18+.

```sh
npm install
npm run server
```

В другом окне:

```sh
npm run dev
```

Откройте http://localhost:3000. Vite проксирует `/api` на Express (порт 4000). Сборка: `npm run build`. Для локального preview: `npm run build`, затем `NODE_ENV=production npm start` и открыть порт 4000.

Для локальной демо-панели задайте случайный секрет в среде сервера, например `ADMIN_TOKEN=change-this-local-demo-secret npm run server`; токен вводится в профиле. Не используйте этот режим в публичном интернете.

## Что реализовано в песочнице

- Пять экранов и API: профиль, обзор, история, тестовый баланс, демонстрационные уровни, шаринг ссылки.
- Симулированное начисление по времени и уровню; ручное зачисление демо-прибыли.
- Демо-пополнение, сундуки с наградами, настройка процента рефбека.
- Демо-заявка на вывод: проверка суммы/баланса, лимит пяти micro-заявок до 10 USDT и журналирование.
- Ограниченная ADMIN_TOKEN панель: просмотр метрик/пользователя/заявок, принятие или отклонение тестовой заявки, редактирование демонстрационных ставок.
- JSON-сохранение для локального теста в `.data/demo-state.json`; файл создаётся автоматически и сбрасывает тестовую базу только при ручном удалении.

## Ограничения

Это только sandbox с одним общим фиктивным пользователем; JSON-файл не является надёжной базой данных и не рассчитан на несколько процессов/пользователей или реальные деньги. Нет проверки Telegram `initData`, регистрации по реферальному коду, трёхуровневых начислений, реальных платежей USDT/TON/Stars, blockchain выплат, KYC/AML, антифрода, проверки Stories, аудируемой админ-системы или AI-торговли. Показанные ставки из исходного концепта используются только для симуляции интерфейса и не гарантируют доход. Не разворачивайте этот проект как финансовый продукт.

Для продакшена потребуются отдельные юридическая/комплаенс-проверки и разработка авторизации, БД с атомарным double-entry ledger, платежных интеграций и аудита безопасности; эта демо-реализация их не заменяет.
